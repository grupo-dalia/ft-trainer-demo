# Plantillas de correo FT Trainer

Preparadas para los seis correos de autenticación de Supabase: confirmación, invitación, enlace mágico/OTP, cambio de correo, recuperación y reautenticación. Todas usan estilos en línea y el logotipo público para ser compatibles con Gmail y clientes móviles.

Supabase Hosted solo permite editarlas después de activar SMTP personalizado. Configuración prevista para Gmail: servidor `smtp.gmail.com`, puerto `587`, usuario/remitente `ftienda4@gmail.com` y una contraseña de aplicación de Google (no la contraseña normal de la cuenta).
